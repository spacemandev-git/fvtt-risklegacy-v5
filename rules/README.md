# Risk Legacy Rulebook (Markdown Transcription)

This is a transcription of the 2011 Risk Legacy rulebook, `assets/rules.pdf` (16 pages, Hasbro / Parker Brothers). The text follows the printed rulebook; it was transcribed from the PDF and checked against each page image.

The rulebook has blank boxes where rule stickers are applied as the campaign unlocks. They are kept here as placeholders and not filled in.

## Conventions

- `<!-- page N -->` marks where PDF page N begins. Printed page numbers match PDF page numbers (the cover is page 1; page 2 is printed "PAGE 2", and so on). A page that is split across two files has `<!-- page N (continued) -->` at the start of the second file (pages 8, 12 and 15).
- The `# ` title at the top of each file is an editorial file title. Everything below it follows the book's own headings, with the printed capitalization kept for headings.
- Text is verbatim, including the book's own spelling and wording quirks (for example "Khan Industries" in the text but "Kahn Industries" on a card illustration and some concept-art captions, and "Defence dice"). Only line breaks, hyphenation, ligatures and spacing were cleaned up, and quotation marks and apostrophes were straightened.
- Sidebars, callout boxes and notes are blockquotes with their printed title, if any. The circled step numbers in the turn sequence are shown as ❶ to ❺.
- Items in square brackets, such as `[Illustrated example]` or `[Text printed in the illustration]`, are editorial labels and not part of the book's text. The same goes for all HTML comments.
- Words printed inside illustrations (hand-lettered labels, text on sealed cards, text on cards and stickers) are in the image descriptions or in a line labelled as illustration text next to the figure.
- Decorative art (cover art, concept sketches, faction portraits, board and component photos that illustrate no rule) was not extracted. Each such place has an HTML comment saying what it is.
