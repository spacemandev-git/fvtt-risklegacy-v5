# Risk Legacy content catalog (`data/content/`)

> **Spoilers.** This folder contains the transcribed text of every sealed pack and pocket.

Generated by `python3 tools/content/build.py` (rerunnable; `--check` validates without writing). Do not edit
the JSON by hand: the mechanical parts (ids, image paths, quantities, territory faces) come from
`assets/unlocks/<pack>/<folder>/cards.yaml`, and everything read off the card images (text, card codes,
rule-box letters, `effect` / `check` hints) lives in `tools/content/transcriptions/<pack>.yaml`, which the
script merges on top. Edit the transcription files and rerun. This README is generated from
`tools/content/README.template.md`.

## Conventions

- **Paths** are relative to the system root (`assets/unlocks/...`). All of them were checked case-sensitively.
- **Ids** are snake_case and unique within their category across all packs. Files called `evolution_N.jpg`
  exist in six packs, so their ids carry the pack prefix (`minorcities_evolution_1`). The same id may appear in
  two categories when they describe the same thing (mission `advanced_tactics` and its power
  `advanced_tactics`; scar `primitive` and weakness power `primitive`; mark `fallout_zone` and sticker
  `fallout_zone`). Every entry built from a `cards.yaml` document has `source: { yaml, key }`
  (`renamedFrom` when the id differs from the YAML key).
- **Text** (`text`) is the printed text, verbatim, with these normalisations: straight quotes and apostrophes;
  paragraphs separated by `\n\n`, bullet lines by `\n`; words hyphenated across a printed line break re-joined
  ("home-land" → "homeland"); bold/italic dropped (emphasis in capitals such as DESTROY / DISCARD / EITHER is
  kept); a missing space after a comma on J163 ("eliminated,he") fixed. Editorial notes are in square brackets.
  No text was illegible (no `[illegible]` markers).
- **`textSource`** tells where the text came from: `card` (transcribed from the scan), `yaml` (the
  `description` in `cards.yaml`; used where no scan exists: starting, knockout, missile and secret mutant
  powers), `init.js` (hard-coded in the old importer: mutant and alien faction-card powers), `rulebook`
  (sticker-sheet rewards, from `rules/10-end-of-game.md`). Only `card` text has been checked against an image.
- **`code`** is the small card code printed bottom right (A = base, B = minorcities, C = eliminated,
  D = secondwin, E = worldcapital, J = threemissiles, K = thirtytroops; an `s` suffix marks a card with
  stickers). Only one face of multi-copy cards is scanned, so codes of the other copies are not known.
- `effect` / `check` are **hints** for automation: only present where the rule is simple and unambiguous,
  otherwise `null`. `automation` on powers is a stable switch key (= the power id). The printed text is
  always authoritative.

## Category semantics

| key | what it holds |
| --- | --- |
| `warProgresses` | "THE WAR PROGRESSES" cards (narrative + sorting instructions, read aloud in `order`). The files named `rules/images/evolution_N.jpg` are these cards, **not** Evolution cards. When the card also carries a sticker, `sticker: { kind, ref, text? }` points at the entry describing it (`kind`: `boardReference`, `mark`, `factionScar`, `weakness`; `ref`: `"<category>:<id>"`). |
| `factions` | `{ id, name, img, color, pieces: { troop, triple, hq } }`. `img` is character art, not a scan of the faction card. |
| `powers` | Faction-card stickers / printed powers. `slot`: `starter` (green), `mission` (red private mission), `weakness` (yellow), `missile` (brown), `knockout` (blue comeback power), `scar` (faction-card scar such as Bringer of Nuclear Fire), `other`. `limitation: true` marks printed "cannot take a … power" restrictions. `cost: { missiles, perTurn }` for missile powers. `scar` / `mission` link a power to the card that delivers it. Mission powers also carry `check`. |
| `secretPowers` | Same shape as powers; the mutant powers under the faction card's scratch-off boxes. `evolution: { approach: offensive\|defensive, target: bodies\|brains }` is the pair of Mutants Evolve choices that reveals it. |
| `territoryCards` | `{ id, name, continent, value, faces: { original: [6], advanced: [6] }, back }`. `faces.<variant>[n-1]` is the face showing *n* resources; `null` only below the starting `value` when no art exists (Alien Island 1-2). `value` is the starting value. `continent` is `null` for Alien Island. |
| `coinCards` | `{ count, value, img, back, code, text }` (base only). |
| `scars` | Scar cards dealt before a game. `target`: `territory` (placed on the board) or `faction` (weakness scars, placed on a faction card's yellow slot). `cardImg` = the card, `stickerImg` = the round scar sticker (weakness scars have no separate sticker art, so it is the card). `play: { timing, where, requires }`. `power` links weakness scars to their power. |
| `stickers` | Physical stickers/marks a pack supplies. `group`: `beforeFirstGame`, `heldOn`, `won` (the base sticker-sheet sections) or `other`. Stickers printed on a card with no separate art use the card image. |
| `events` | `afterResolve`: `box` (the card says DISCARD; discarded events go back to the box, rulebook p.13), `destroy` (DESTROY), `keep` ("Keep this card in the game box" - Mutants Evolve), `other` (conditional; see `afterResolveText`). `player`/`deck` from the requested vocabulary are not used by any card. |
| `missions` | `reward` = Red Stars (red-star icons on the card). `private: true` for private missions. `afterComplete`: `box`, `destroy`, `destroyIfStickerApplied` (private missions). `stickerText` = the red sticker on private missions. `opens` = pack id opened by completing it. |
| `draft` | `type`: `coin`, `placement`, `troops`, `turnOrder`. `players` = number in the corner (use the card when at least that many players play). `value` = coins / placement position / troops / turn position. |
| `rules` | `kind: "addition"` = rulebook sticker (`addition` = box letter A-N, `page`, `inferred`, `inferredFrom`, `replaces` = printed rulebook text it replaces, `stickerIndex` when one card carries two stickers). `kind: "reference"` = sticker for the reference-sticker space on top of the game board (`scar` / `mark` link). |
| `marks` | Rules definitions of special board marks introduced by a pack (World Capital, Fallout Zone, Alien Island, Ruins), with `effect` and the ids of the `rules` that govern them. |

`trigger.when`: `beforeFirstGame`, `endOfGame`, `midGame`, `midOrEndOfGame` (from the rulebook's "Opening New
Packages" panel, quoted in `trigger.rulebook`). `trigger.sealedText` is the label printed on the sealed card.

## Vocabularies

### `timing` (powers)
`startOfTurn`, `recruit`, `attack`, `defend`, `maneuver`, `endOfTurn`, `drawCard`, `passive`, `anytime`, plus
two added values: `expand` (applies when expanding into a territory) and `setup` (applies at the start of the
game). `anytime` powers carry `trigger`: `beforeCombatRoll`, `playerDrawsResourceCard`,
`startOfOtherPlayersTurn`. Mission powers use `endOfTurn` (missions are claimed at the end of a turn; the
`check` may carry its own `when`).

### `play` (scars)
`timing`: `beforeAttackRoll`, `startOfAnyTurn`, `duringOwnTurn`. `where`: `defendingTerritory`,
`anyUnscarredTerritory`, `factionYellowSlot`. `requires`: `unscarred`, `emptyYellowSlot`.

### `effect.type`
Selectors used inside effects: `who` = `largestPopulation`, `everyPlayer`, `alienPlayer`, `mutantPlayer` or
`{ controllerOf: <territoryId> }` (rulebook p.13: on a tie, or if that faction is not playing, the event does
not occur). Faction ids in `exempt`.

| type | fields | meaning / used by |
| --- | --- | --- |
| `dieMod` | `side` (attacker\|defender), `die` (highest\|lowest\|all), `delta`, `condition?` | Modify combat dice (never above 6 / below 1; one die per source). Conditions: `firstTerritoryAttackedThisTurn`, `defendingTerritoryHasHQ`. Bunker, Ammo Shortage, enclave_1, well_armed. |
| `endOfTurnTroops` | `delta` | At the end of the controlling player's own turn, add/remove troops in the territory. Bio-Hazard (-1), Mercenary (+1), Fallout Zone (-1). |
| `enterLoss` | `fraction`, `round` | Troops entering (expanding/conquering) lose that fraction. Fallout Zone. |
| `noPlaceTroops`, `noManeuverThrough`, `unmodifiable`, `destroyTerritoryCard` | - | Fallout Zone restrictions. |
| `all` | `effects[]`, `exempt?` | All sub-effects apply; listed factions are exempt. |
| `choice` | `who`, `options[]` | The selected player picks one option. Options may carry `afterResolve`. |
| `placeTroops` | `who?`, `where`, `count`, `targets?`, `perTarget?`, `split?`, `optional?` | Add troops. `where`: `eachControlledHQ`, `drawnTerritoryIfControlled`, `oneControlledCity`, `upToTwoControlledCities`, `controlledCities` or `{ unoccupied, city }`. `split`: may be divided between targets. |
| `removeTroops` | `who`, `where`, `count`, `perTarget` | Remove troops. `where`: `{ cityType, troopsMin, troopsMax }` or `{ adjacentByLandTo: <markId> }`. `count` may be a dice string (`"1d6"`, rolled per target). |
| `maneuver` | `count` | Make an immediate extra maneuver. |
| `placeMark` | `mark`, `where`, `requiresSupply` | Place a sticker/mark (if any are left). |
| `chooseMission` | - | Replace the face-up mission with one chosen from the deck, then reshuffle. |
| `gainRedStar` | `who`, `count`, `condition` | Condition `noHumanFactionHasContinentBonus`. |
| `gainMissiles` | `count`, `condition` | Condition `mutantsInPlay`. |
| `chooseEvolution` | `who`, `axis` (approach\|target), `options` | Mutants Evolve; see `secretPowers[].evolution`. |
| `ruinCity` | `who`, `where: { cityType }`, `optional`, `afterResolve` | Replace a city with a Ruin; remove all troops, demolish any HQ there. |
| `takeTerritoryCard` | `who`, `from: faceUp`, `count` | Take a face-up territory card (may trigger another event). |
| `recruitRounding` | `mode: up` | Round (territories + population) / 3 up. |
| `scarModifier` | `scar`, `delta` | Change a scar's per-turn troop effect for this faction. |
| `ignoreScar` | `scar`, `side` | The faction is unaffected by that scar. |
| `reverseScar` | `scars[]` | The scars' effects are reversed for this faction. |
| `winTies` | `side`, `value` | That side wins ties on dice showing `value` (unnatural_strength). |
| `factionPower` | `power` | A weakness scar: apply the linked power to the faction. |
| `city` | `cityType` (minor\|major\|worldCapital), `population`, `legalStartFor?`, `leadFactionStartTroops?` | City mark. |
| `fortification` | `defenderDieDelta`, `expandExtraTroops`, `uses`, `usedBy` | +1 to both defence dice, +2 troops to expand into an unoccupied fortified city, one box marked per 3-troop attack, 10 boxes. |
| `upgradeTerritoryCard` | `delta`, `max` | Coin sticker on a territory card (max 3 before the first game, 6 after). |
| `cancelScar` | - | White sticker over a scar. |
| `continentBonusMod` | `delta` | +1 / -1 continent mark. |
| `seaLine` | `to?` | Sea-line start sticker: new connection drawn in pen. |
| `mark` | `mark` | The sticker is the board mark described in `marks[]`. |
| `newTerritory` | `territory`, `continent`, `seaLines`, `island` | Alien Island becomes a territory. |
| `ruin` | - | Ruin mark: the territory no longer contains a city; cannot be fortified; a city can be rebuilt over it. |

| `controlIslands` | `count` | Explore the World (island = territory connected to others only by sea-lines) |

| `controlTerritoriesWithCities` | `count`, `cityType?` | Superior Infrastructure, Urban Troop Surge |

## Rulebook addition boxes (A-N)

{{ADDITIONS}}

How the letters were assigned:

- **B, C, D, E, F are given** by the file names (`pg7panelB/C/D`, `pg12PanelE`, `pg12panelF`) and confirmed by the
  HTML comments in `rules/04-…md`, `rules/07-…md` and `rules/08-…md`. The B/C/D stickers replace the printed text
  (copied into `replaces`). The C box is printed taller than its text, and B68s is the longest sticker.
- **A and G-N are inferred.** Only the fronts of the Evolution cards were scanned; the backs, which name the box,
  were not. Exactly nine rulebook stickers remain for the nine remaining boxes: E124s, E125s, E126s, J167s (two
  stickers), J168s, J169s and K185s (two stickers).
  - **A** (p.7, Player Set Up, right after the Red Star / Missile token rules) ← *Bringer of Nuclear Fire*
    (J167s, 2nd sticker): it gives Missile tokens at the start of the game "in addition to any tokens received
    by the player".
  - **M, N** (the two shorter boxes on p.13) ← the two short stickers on K185s, *Alien Island* and *Ruins*.
  - **G-L** ← the rest in card-code order: G Private Missions (E124s), H Lead Faction (E125s), I World Capital
    (E126s), J Missile Powers (J167s, 1st sticker), K Fallout Territory Part 1 (J168s), L Part 2 (J169s).
  - Treat these as a best guess (`"inferred": true`). Lead Faction could equally be meant for A.

## Open questions

- **Alien Island territory card** (K186) only has art for 3-6 resources and a single art set for both board
  variants: `faces.original` = `faces.advanced`, with `null` at index 0-1 (it starts at 3 and only gains
  resources). `continent` is `null` (`cards.yaml` says `"None"`).
- **Unscanned cards.** No scans exist for the starting-power stickers (text from YAML), the knockout, missile
  and secret mutant powers (text from YAML), the mutant and alien faction cards (text from `init.js`), the backs
  of the Evolution cards (box letters), or the extra copies of multi-copy cards. Gaps in the card codes that
  are not explained by copies: B66 (probably the Bio-hazard reference sticker card, cropped into
  `biohazard_rules.jpg`), C102 (probably the Mercenary reference card, cropped into `mercenary_rules.jpg`),
  C104-C105 (probably the comeback-power stickers), J176-J177 (probably the missile-power stickers). The
  Alien Island territory card is K186.
- **Alien private mission reward.** `init.js` says 2 Red Stars, K184 says one Red Star once per game.
- **Alien starting power** says "enemy cities" in `init.js`; probably "empty cities".
- **Mutant faction powers** come from `init.js`: one starter, one private mission, two printed knockout
  powers and two limitations. The names (e.g. "Mutants: Revenge") are editorial.
- **Ruins quantity** (3) is inferred from the three Die Humans cards; `cards.yaml` gives none.
- **Mutant / alien colours** were not supplied: mutants `#c8862a` (ochre, mutant HQ token), aliens `#2e76d0`
  (blue, alien HQ token). Faction ids are `mutants` and `aliens` (from the YAML namespaces).
- **Fortify / Die Humans** have conditional disposal (`afterResolve: "other"`): DESTROY if the fortify option
  is chosen / a city is ruined, otherwise DISCARD.
- **Riots** has `effect: null` (per-major-city roll with troop/HQ modifiers; implement from the text).
- **Asset/YAML quirks** (no effect on the output): `base/stickersheet/images/cancel.png` is a blank white
  128×113 placeholder; `biohazard_rules.jpg` and `mercenary_rules.jpg` are used by the old `init.js` but are not
  in any `cards.yaml`; the weakness scars' `tokenImg` is the card itself; the `deck.yaml` files of
  threemissiles (partly) and thirtytroops use `namespace:` instead of `deck_name:`; `secretmutantpowers` encode
  the Mutants Evolve choices in the namespace prefix (`DEFENSIVE-BRAINS.mass_hypnosis…`) and are typed
  `weakness` only to get a yellow icon; the YAML power types of the mutant/alien powers in `init.js` are
  colour hacks too (Bringer of Nuclear Fire was typed `mission`). Power, knockout and secret-power names are
  generated from the YAML ids (no scans show them).
